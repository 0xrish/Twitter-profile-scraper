What it does

The Actor auto-detects what you're after — profiles, tweets, replies, or media — and delivers clean, structured data instantly. Give it usernames, profile URLs, or search terms; it handles the rest.

  • Profile information — bio, followers, following, location, website, join date, avatar, banner
  • Tweets and posts — full text, timestamps, hashtags, mentions, URLs, engagement metrics
  • Replies and conversations — threaded reply tweets with full context
  • Media content — tweets containing images, videos, and GIFs
  • Retweets and quote tweets — including original author metadata
  • Search results — keyword search within a profile or globally

How to scrape X (Twitter)

  1. Click Try for free on the Actor page.
  2. Enter Twitter handles (e.g. elonmusk, apify) or paste profile URLs.
  3. Configure scraping options — replies, media-only, or profile info.
  4. Optionally apply filters — date range, engagement thresholds, content type, or search keywords.
  5. Click Run.
  6. Preview or download your data from the Dataset tab once it finishes.

The Actor routes each request to the right scraping mode automatically — no manual configuration needed.

Tips for scraping X effectively

  • Start small — set maxItems to 20–50 on the first run to validate configuration.
  • Use minLikes or minRetweets to surface high-quality content.
  • Combine include and exclude filters for precise targeting — e.g. media only, no replies.
  • Set startDate/endDate on large collections to avoid over-scraping.
  • Enable residential proxies for the most reliable results at scale.
  • Handles are processed in parallel automatically for faster runs.
  • Failed requests retry automatically with exponential backoff.

Frequently asked questions

Can I scrape private Twitter profiles?

No. Twitter X Profile Scraper only works with public profiles. Private or protected accounts cannot be scraped.

Do I need a Twitter API key or account?

No. This Actor requires no Twitter API credentials, cookies, or authentication, and works independently of the official Twitter API.

What export formats are available?

JSON, CSV, Excel (XLSX), XML, RSS, or an HTML table, directly from the Apify Console Dataset tab.

How many tweets can I scrape?

On paid plans there's no hard cap — set maxItems to 0 for unlimited. Free-tier users get up to 5 runs per day with up to 10 items per target.

Can I search for specific keywords within a profile?

Yes — use searchTerms to search within a profile's tweets, with support for AND/OR operators.

Is it legal to scrape X (Twitter)?

Personal data is protected under GDPR and similar regulations worldwide. Don't scrape personal data without a legitimate reason, and review X's Terms of Service before scraping. Always scrape responsibly.

Python quick start

from apify_client import ApifyClient

client = ApifyClient("<YOUR_API_TOKEN>")

run_input = {
    "twitterHandles": ["figma"],
    "maxItems": 20,
    "proxyConfiguration": {
        "useApifyProxy": True,
        "apifyProxyGroups": ["RESIDENTIAL"],
    },
}

run = client.actor("mikolabs/Twitter-X-Profile-Scraper").call(run_input=run_input)

print(f"Dataset: https://console.apify.com/storage/datasets/{run.default_dataset_id}")
for item in client.dataset(run.default_dataset_id).iterate_items():
    print(item)
